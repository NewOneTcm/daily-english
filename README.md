# 每天用英语

一个自用的英语学习工具：每天开机弹出，读一段英文、划不认识的词、AI 解释、造句、AI 点评，学完就走。不打卡、不签到、不积分。

## 它能做什么

- **今天**：每天一张任务卡（听说读写轮换），做完打卡
- **精读**：粘贴你想读的英文，划词查词、AI 解释、存生词
- **场景阅读**：把你不熟的词编成一篇短文，在语境里反复遇见
- **生词库**：所有划过的词在这里精加工（解释 → 造句 → AI 点评 → 存学习库）
- **表达库**：收集地道表达和你的错误，导出给 SuperMemo 长期记忆
- **听写**：把生词转成拼写挖空题，导出给 SuperMemo
- **复习**：听力跟读（shadowing）
- **统计**：学习时长、新学内容的可视化

## 快速开始

### 1. 直接用（最简单）

双击 `index.html` 就能用，数据存在浏览器本地（localStorage），不需要安装任何东西。

### 2. 配置 AI（可选，但强烈建议）

没有 AI 也能用（本地点评、TTS 发音都离线可用），但 AI 能做的事多得多（语境解释、深度点评、场景阅读生成）。

在「记录」页配置：

- **接口地址**：OpenAI 兼容的 API 地址（如 `https://api.deepseek.com/v1`、Kimi、或本机中转 `http://127.0.0.1:8787`）
- **模型**：如 `deepseek-chat`、`kimi-k2` 等
- **API Key**：本机中转可不填

配好点「测试连接」确认通畅。

### 3. 数据在哪

- 数据存在浏览器 localStorage，换浏览器/清缓存会丢
- 想备份：「记录」页导出数据；想换电脑：导出 → 在新电脑导入
- 建议定期导出备份

## 常见问题

**Q: 数据安全吗？**
A: 全在本地，不上传任何服务器。AI 调用只走你配置的接口。

**Q: 能用手机吗？**
A: 界面是桌面优先的，手机能开但体验一般。建议电脑用。

**Q: 怎么导到 SuperMemo？**
A: 「表达库」/「听写」页导出 `.txt` 文件 → SuperMemo 里 `File : Tools : Import : Q&A text` → **务必勾选 "Decode UTF-8"**（否则中文乱码）。

**Q: 生词太多不知道从哪开始？**
A: 生词库顶部有「今日任务」，按优先级给你 6 个该处理的词，点词直接跳转。

## 技术说明

- 纯前端，无后端，无框架（原生 HTML + JS）
- 数据存储：localStorage
- AI：OpenAI 兼容接口
- 发音：浏览器内置 TTS（离线）
